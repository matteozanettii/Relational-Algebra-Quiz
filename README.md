Welcome to the **Relational Algebra Interactive Master Quiz**! 🎓

This repository hosts a lightweight, single-page interactive web application designed to help Data Science students test and improve their skills in Relational Algebra. The questions are directly based on the official exercise materials from the **Structured & Unstructured Data Management** course (A.A. 2026/2027) at the **University of Parma**, authored by Prof. Letizia Marchegiani[cite: 1].

## ✨ Features

* **🎲 Dynamic Randomization:** Uses the Fisher-Yates algorithm to shuffle both the order of the questions and the multiple-choice options every time you play, preventing simple memorization.
* **📐 Crisp Math Typesetting:** Integrated with [KaTeX](https://katex.org/) to render complex relational algebra operators ($\sigma$, $\pi$, $\bowtie$, etc.) beautifully and flawlessly.
* **📊 Interactive Schema Viewers:** Not sure what the database looks like? Click the "View Database Schema Tables" dropdown on any question to instantly see the relevant table structures before answering.
* **⚡ Instant Feedback:** Get immediate grading on your answers along with detailed explanations for why an option is correct or incorrect.
* **📱 Fully Responsive:** Built with Tailwind CSS, meaning you can practice on your laptop, tablet, or smartphone.

## 🚀 How to Use

No complex local environments, build steps, or servers required.

1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser.
3. Start testing your knowledge!
